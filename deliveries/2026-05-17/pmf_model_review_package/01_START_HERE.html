How to view this package

  1. 02_MODEL_REVIEW_OVERVIEW.html — opens in any browser. Shows the slate, the model version, per-stat counts, and quality-flag rollup.
  2. 03_PMF_DISTRIBUTION_VIEWER.html — opens in any browser. Renders every PMF as a small histogram, grouped by stat. Use this to eyeball shape, peak, and tail before consuming the numbers.
  3. 04_PROP_SUMMARY.csv — opens in Excel / Google Sheets. One row per (player, stat) with mean, median, mode, p0, role, market context (if any).
  4. 05_FULL_PMF_WIDE.csv — same rows, with pmf_json (the full PMF as JSON) and the p_ge_1 … p_ge_20 tail ladder.
  5. 06_OUTCOME_LEVEL_PROBABILITIES.csv — long format. One row per (player, stat, k) with P(outcome=k). Useful for plotting tools.
  6. machine_readable/model_only.parquet — the same content as 05_FULL_PMF_WIDE in parquet form, full numeric precision. This is the canonical artifact.

What's NOT in this package

  • No book lines, no edges, no recommendations. Those live in the separate wizard_of_odds/ package.
  • No backtests or claims of profitability.
