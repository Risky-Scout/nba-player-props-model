This package contains standalone model PMFs for the 2026-04-27 late NBA slate (OKC @ PHX 21:30 ET; MIN @ DEN 22:30 ET). The canonical PMFs are model-only.

What's in this package

How the model PMFs were built

  • Source predictions come from the local pregame predict pipeline output.
  • Each raw PMF is active-conditioned: pmf_active = active_condition_pmf(raw_pmf, p_inactive), where p_inactive comes from the locally-computed minutes distribution.
  • Role-aware Phase-8 calibration: RoleAwarePMFCalibrator.apply(pmf_active, role_bucket=…) across six buckets (inactive_risk, fringe, bench, rotation, core, starter).
  • FG3M only: validated tail-shrink at k ≥ 7 with weight w = 0.2 (mass-preserving), correcting the upper-tail overshoot from the Phase-8 audit.

Calibration / backtest evidence

  • Phase 8 walk-forward OOF: 247,625 rows (15 folds × 5 stats). 0 validity failures.
  • Role-aware calibration: 6 buckets. Active-conditioned target.
  • PTS/REB/AST/TOV: stat-level Δnll −0.028 to −0.073 vs raw; calibrated mean within ~1% of observed; calibrated p_over at standard lines within 0.005 of observed; all 30 (stat × bucket) cells improved.
  • FG3M tail correction (k≥7, w=0.2) selected by time-safe grid validation. Mean error +0.293 → +0.012; P(k≥7) error +0.020 → −0.001.
  • Matched closing-line audit (n=3,818): de-vigged closing market beats standalone calibrated model on log-loss in 9 of 11 cohorts (95% CI). No standalone market-beating claim is made.

Honest limitations

  • No standalone market-beating claim. The model did not beat the closing market on the latest matched audit.
  • Source predictions are from the morning predict run (mtime ~14:27 ET 2026-04-27). Late-breaking injuries / lineup changes may not be fully reflected.
  • Local availability table is stale (last refreshed 2026-04-18, 0 rows for 2026-04-27). Player-active priors fall back to history.
  • TOV is absent from this slate because the source all_props file contained no TOV offerings for these two games.
