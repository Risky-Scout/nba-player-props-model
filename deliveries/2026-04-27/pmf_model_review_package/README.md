# PMF Model Review Package — 2026-04-27 Late NBA Slate

This is a clean reviewer-facing package for the standalone calibrated
player-prop PMFs covering the 2026-04-27 late NBA slate (OKC @ PHX,
MIN @ DEN). All files in this folder are derived from the canonical
MODEL_ONLY parquet committed in the sibling `live_after_2029_et/`
folder — the underlying model PMF values are NOT modified here.

## Recommended viewing order

1. **`01_START_HERE.html`** — index page.
2. **`02_MODEL_REVIEW_OVERVIEW.html`** — visual overview with counts and example PMFs.
3. **`03_PMF_DISTRIBUTION_VIEWER.html`** — full self-contained dashboard.
4. **`04_PROP_SUMMARY.csv`** — one row per (player × stat).
5. **`05_FULL_PMF_WIDE.csv`** — one row per (player × stat), one column per outcome (`prob_0`, `prob_1`, …, `prob_N`). **Easiest spreadsheet view.**
6. **`06_OUTCOME_LEVEL_PROBABILITIES.csv`** — one row per (player × stat × outcome_k).

For machine-readable raw files (parquet, JSONL, and the CSV with
embedded `pmf_json`), see `machine_readable/`.

## Honest contract

- **The PMFs are standalone model outputs, not market-anchored.**
- Market columns (`line`, `market_fair_over_prob`, `model_edge_vs_market`)
  are comparison references only and do not modify the PMF values.
- The latest matched closing-line audit found the de-vigged closing
  market beats the standalone calibrated model on log-loss in 9 of 11
  cohorts (95% CI). **No market-beating claim is made.**
- See `MODEL_EVALUATION_SUMMARY.md` for the full breakdown.

## Reproducibility

This package is generated by `scripts/build_pmf_review_package.py`,
which reads only:

- `deliveries/2026-04-27/live_after_2029_et/player_prop_pmfs_tonight_MODEL_ONLY.parquet`
- `deliveries/2026-04-27/live_after_2029_et/MODEL_EVALUATION_SUMMARY.md`
- `deliveries/2026-04-27/live_after_2029_et/pmf_calibrators/pmf_cal_meta.json`

and writes only into this folder. No model math, calibrator, workflow,
or canonical-data file is touched.
